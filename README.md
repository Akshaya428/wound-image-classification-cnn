# wound-image-classification-cnn
Dual-channel CNN for wound image classification using RGB and texture (LBP) features for healthcare applications.

## Overview
This project focuses on automated wound image classification using a dual-channel
Convolutional Neural Network that combines RGB images and texture-based LBP features.

## Problem Statement
Accurate wound classification is essential for timely diagnosis and treatment.
Manual assessment is subjective and time-consuming, motivating the need for
automated image-based solutions.

## Dataset
- Wound image dataset
- Medical images captured under varying conditions
- Preprocessing applied to improve robustness

## Methodology
- Dual-channel CNN architecture
- RGB image stream + LBP texture stream
- Image preprocessing and data augmentation
- EfficientNet backbone

## Results
- Improved robustness compared to single-channel models
- Demonstrated effective feature learning for wound classification

## Tools & Technologies
Python, TensorFlow/PyTorch, Google Colab, OpenCV
